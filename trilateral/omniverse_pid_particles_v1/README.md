# Asolaria Floor-1 omniverse PID particles

This package is the cold trilateral preparation for training the Asolaria neural
network, matrix, and fabric on reversible cube/PID bodies. It treats this
repository's metatagging model as the foundation grid and particle-address
ontology of Asolaria, not as an unrelated dataset.

The executable model covers:

- content-addressed cube PIDs with 60D+ route selectors;
- six-apex C2^3 cube geometry;
- twelve directed tetrahedral transitions;
- finite triangular sphere refinements whose limit carries the pi geometry;
- arbitrary finite nested addresses and BigInt question indices;
- typed held-out/evaluator precommits and deterministic/stochastic improvement
  claims whose confidence bounds must clear measured noise;
- 34 reconstructable native-glyph witness identities for the sealed 27+6+1
  formation, without inventing unimported catalog bytes;
- five independent glyph-language evaluation gates for composition,
  reversibility, cross-cube meaning, and native-language retention;
- catalog events for messages, errors, ideas, glyphs, questions, and answers;
- paired forward-GNN and reverse-gain proposals;
- a six-way Omega GNN bound to the trained Omega omnibit;
- a two-response sister collision table visible to supervisors;
- a Path 3 digital projection/replay cell keyed by the Omega keystring;
- finite cycle-double-cover audit fixtures for cube and tetrahedron surfaces.

The module is intentionally non-firing. It imports no network or process API.
Prepared edges retain **learned=0** until an owning GNN receipt says otherwise.

## Verify

From the repository root:

~~~bash
python3 -m unittest -v trilateral.omniverse_pid_particles_v1.test_model
python3 -m trilateral.omniverse_pid_particles_v1.prepare verify \
  --output trilateral/omniverse_pid_particles_v1/artifacts
~~~

Rebuilding the sealed packet additionally requires the exact LIRIS CDC group
receipt pinned by SHA-256:

~~~bash
python3 -m trilateral.omniverse_pid_particles_v1.prepare build \
  --output trilateral/omniverse_pid_particles_v1/artifacts \
  --cdc-group-receipt /path/to/CDCLEAN-PAIS-OMEGA-CUBIC-GROUP-RESULT.hbp
~~~

The artifacts are LF-only HBP/HBI/SHA/hex. The HBI indexes every HBP row by
zero-based byte offset and SHA-256; the hex mirror reconstructs the HBP bytes.

The full architecture and evidence boundary are documented in
[the Floor-1 Omegaverse specification](../../docs/ASOLARIA-FLOOR1-OMEGAVERSE-TRILATERAL-PREPARATION-2026-07-15.md).
